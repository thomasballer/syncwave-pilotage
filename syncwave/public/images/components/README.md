# Crédits et nature des visuels

Catalogue ajouté le 29 octobre 2026. Ces visuels aident à reconnaître les familles de pièces et ne constituent pas un inventaire photographique du matériel de l’équipe.

## Photos fabricant / concepteur

- `pico.png` — Raspberry Pi. Vue de la gamme Pico, modèle standard au centre ; les autres variantes visibles ne sont pas attribuées au projet. Source : https://www.raspberrypi.com/products/raspberry-pi-pico/ — image : https://assets.raspberrypi.com/static/hero-mobile-226918a036a9f3717d04170387cd439e.png
- `modem.jpg` — Waveshare. Carte Pico-SIM7080G-Cat-M/NB-IoT, distincte du HAT pour le Raspberry Pi à 40 broches. Source : https://www.waveshare.com/Pico-SIM7080G-Cat-M-NB-IoT.htm
- `led.jpg` — SparkFun Electronics. Exemple de module WS2812B BOB-13282 ; ce format n’est pas confirmé pour la LED de l’équipe. Source : https://www.sparkfun.com/sparkfun-rgb-led-breakout-ws2812b.html

Les fichiers photo sont conservés sans retouche. Les crédits et les liens source apparaissent également dans les fiches du catalogue.

## Illustrations

Les fichiers SVG sont des illustrations originales de repérage réalisées pour le catalogue Syncwave. Ils ne donnent pas de plan de raccordement, de dimensions réelles, de modèle batterie ni de référence de convertisseur. Les SVG Pico, modem et LED servent uniquement de visuels de secours si une photo ne se charge pas.
